# Project knowledge base

Read this before working on the site. It saves you from re-exploring 20+ GB of
drives, three repos and the web. Everything here was verified against primary
sources in September 2026. Where sources disagree, the file says so.

| File | Read it when you need… |
|---|---|
| [project.md](project.md) | what TSOE is, the key ideas and vocabulary, history, format, names and spelling |
| [people.md](people.md) | team, musicians, roles, affiliations, bios, links, other credits |
| [physics.md](physics.md) | the physics for the explainer page, in layers, plus what the site must *not* claim |
| [pieces.md](pieces.md) | BruQner, 8 Rooms, Indeterminate Apparatus: how each works, performers, media |
| [shows.md](shows.md) | every show and talk, verified dates, upcoming dates, resolved discrepancies |
| [publications-press-media.md](publications-press-media.md) | paper, talks, videos, press articles with URLs, quotes |
| [data.md](data.md) | the real measurement logs, the web excerpts and their encoding, the simulator, the point cloud |
| [visual-language.md](visual-language.md) | the project's existing visual grammar: rings vs lines, Alice/Bob colours, BruQner shader sections |
| [assets.md](assets.md) | where photos, audio, video, figures and logos are, credits, and what must never be copied |
| [content-guide.md](content-guide.md) | how to add or update shows, photos, pieces, people and publications on the site |
| [open-questions.md](open-questions.md) | unresolved facts and permissions to ask the team about |
| [research/](research/) | the raw research dossiers (long and detailed, with full source paths). Use them to dig deeper. |

Design exploration and decisions live in [`../design/`](../design/).

## Keeping this current

When you learn something new (a new show, a confirmed fact, a new asset), update
the relevant file in the same change. When an open question is answered, tick it
in `open-questions.md` and move the fact where it belongs.
